# LiftSync（重訓節奏與數據同步）PWA

重量訓練紀錄 App：課表範本、組間休息計時、器械動作庫、進度圖表、資料備份。
這是 PWA（漸進式網頁 App），放上網站後，手機「加入主畫面」就能像 App 一樣使用，離線也能開。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | App 本體（介面與程式都在這裡） |
| `manifest.webmanifest` | App 名稱、圖示、顏色，讓手機知道它可以安裝 |
| `sw.js` | Service worker，負責離線快取 |
| `icons/rounded/` | 圓角圖示（favicon 與 Android 桌面圖示，16–1024px） |
| `icons/ios/` | 方形圖示（iPhone／iPad 加入主畫面用，iOS 會自己切圓角，20–1024px） |
| `icons/maskable-*.png` | Android 自適應圖示，圖案留了安全邊距不會被裁掉 |
| `icons/LiftSync-icon-*.svg` | 圖示原始向量檔，要改圖或重新產生各尺寸時用 |

> 注意：直接在電腦上雙擊 `index.html` 打開時，離線與安裝功能不會啟用。PWA 必須透過 **https 網址**開啟才有效，所以要先部署。

## 部署到 GitHub Pages（免費）

1. 註冊或登入 [GitHub](https://github.com)。
2. 右上角「＋」→ **New repository**。名稱例如 `liftsync`，選 **Public**，按 **Create repository**。
3. 在新的 repository 頁面點 **uploading an existing file**，把這個資料夾裡的**所有檔案和 `icons` 資料夾**拖進去（不要拖外層的資料夾本身，`index.html` 必須在最上層）。按 **Commit changes**。
4. 進入 **Settings → Pages**。Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
5. 等一到兩分鐘，重新整理該頁，上方會出現網址，例如 `https://你的帳號.github.io/liftsync/`。

其他免費選擇：Netlify（[app.netlify.com/drop](https://app.netlify.com/drop) 直接拖整個資料夾）或 Cloudflare Pages，效果相同。

## 安裝到手機

**iPhone（必須用 Safari）**
1. 用 Safari 打開上面的網址。
2. 點下方的「分享」按鈕 → **加入主畫面** → 新增。

**Android（Chrome）**
1. 用 Chrome 打開網址。
2. 畫面下方出現「安裝應用程式」就直接點；沒有的話，點右上角 ⋮ → **安裝應用程式**（或「加到主畫面」）。

之後從主畫面圖示開啟，就是全螢幕的 App 畫面。

## 休息結束提醒

休息計時區塊裡有「休息結束時提醒」開關。打開後，組間休息倒數到 0 時會**響一聲**；如果那時 App 在背景，還會跳一則通知，點通知可以直接回到訓練畫面。第一次打開會跳出系統的通知授權，拒絕了也沒關係，聲音照常。

**震動不受這個開關控制**，倒數結束一律震一下。但如果你回到 App 時休息已經結束超過 90 秒，就不會再震也不會響 —— 那時你已經在看畫面了，計時器會直接顯示綠色的結束狀態。

計時用的是「結束時刻」而不是累計秒數，所以鎖螢幕、切到別的 App、甚至系統把 App 關掉重開，回來都會接著正確的剩餘秒數（超過 15 分鐘就當作這次休息已經結束）。

幾個做不到的地方，先講清楚：

- **離開 App 時看不到倒數**。網頁 App 沒辦法在自己的視窗外面畫東西，這是瀏覽器的限制，不是設定問題。
- **通知可能會遲到**。手機把背景網頁凍結之後，計時器就不會準時觸發，通知有機會等到你回到 App 才跳出來。想要準時，就讓 App 保持在前景（例如把手機立在臥推架上）。
- **iPhone 要 iOS 16.4 以上**，而且必須是從主畫面圖示開啟的 App，Safari 分頁不會有通知。手機側邊的靜音開關會讓提示音消失，震動還在。

## 記錯了怎麼改

- **改訓練紀錄**：到「紀錄」頁，點任一筆就會打開修改畫面。可以改日期、改每組的重量與次數、刪掉某一組、移除或加入動作，也可以整筆刪掉。改完要按 **儲存修改** 才會生效，按「取消」則完全不動。改到一半切到別的分頁也沒關係，回到「紀錄」會接著改。
- **改體重**：到「進度」頁的「體重」區塊，圖表下方會列出每一筆，直接改數字或按 ✕ 刪掉。
- **改自訂動作**：在「加入動作」面板按 **管理自訂**，可以改自己加過的動作名稱、部位與器材，或把它從動作庫移除。
  - 改名字會一起改掉過去的紀錄、範本與該動作的休息設定，所以統計、個人紀錄、1RM 曲線都不會斷成兩條。
  - 從動作庫移除只是以後選不到它，已經記錄的訓練和範本都會留著；用同樣的名字再加一次，那些紀錄就會接回來。
  - 內建的動作不能改，只有自己用「＋ 自訂動作」加的才可以。
- 修改後，進度圖表、個人紀錄與本週統計都會跟著重算。

## 資料與備份（重要）

- 所有紀錄都**只存在那支手機的 App 裡**，不會上傳到任何地方。
- 在 iPhone 上，主畫面 App 和 Safari 分頁的資料是分開的，請固定從主畫面圖示開啟。
- 刪除 App、清除瀏覽器資料或換手機，紀錄就會消失。請定期到「進度」頁最下方按 **匯出備份**，把 `.json` 檔存到雲端硬碟或傳給自己。新手機安裝後按 **匯入備份** 即可還原。
- 首次開啟會看到範例資料，在右上角按「清除」即可從空白開始。

## 之後要更新 App

1. 修改 `index.html`（或請 Claude 幫你改）。
2. 打開 `sw.js`，把第二行 `VERSION` 的版本號加一，例如 `liftsync-1.0.1` → `liftsync-1.0.2`。**沒改版本號，手機可能一直顯示舊版。**
3. 把改過的檔案重新上傳到 GitHub（同檔名覆蓋）。
4. 手機上把 App 完全關掉再打開，必要時開兩次，就會換成新版。
